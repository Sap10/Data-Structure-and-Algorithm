# Recursion

**Function call itself inside the function**

**Function call itself to solve smaller version of the same problem**

# Two parts of recursion :-

**Base case :-** *Stop condition (when to stop calling itself)*

**Recursive case :-** *Part where function call itself.*

# Real life example :-

**#1. Queue of people.**

**#2. Comment Threads.**

**#3. Organisational Hierarchis**

**Infinte recursion leads to stack overflow**

# Common mistakes :-

*#1. Missing base case - leads to stack overflow*

*#2. Simplifying the input - Never reach the base case, it means the same input given over and over.* 

*#3. Too deep recursion - large inputs*

*#4. Keeping in mind the time complexity*

# When to use recursion :-

*#1. Problems can be broken into sub problems*

*#2. Trees and Graphs*

*#3. Backtracking, DP, Divide & Conquer*
